🛒 Retail / E-commerce Sales Analysis
📌 Project Overview

This project analyzes retail sales data from the Sample Superstore Dataset using Python and Tableau.
The main objective is to understand sales performance, profit trends, customer behavior, and regional business performance to support better business decisions.

📈 Key Insights
Technology category generated high sales revenue.
Some products had high sales but low profit due to discounts.
Western region showed strong sales performance.
Discounts negatively affected profit in some categories.
Consumer segment contributed major sales.
Certain sub-categories showed consistent losses.

🏫 Business Recommendations
Reduce unnecessary discounts on low-profit products.
Focus on high-performing categories and regions.
Improve inventory for best-selling products.
Optimize pricing strategies.
Monitor low-performing sub-categories.
Use dashboard insights for better business planning.
